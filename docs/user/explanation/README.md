# Explanation

Explanation is **understanding-oriented**. These articles discuss concepts,
design decisions, and trade-offs. They help you understand *why* Plynth
works the way it does.

  middleware order matters and what middleware can and cannot do
- [Sync and async in Plynth](sync-async.md) — why there are separate sync
